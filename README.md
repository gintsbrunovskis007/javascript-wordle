# New York Times Wordle - Game Clone

A clone of the famous New York Times Wordle game. It recreates the classic Wordle experience, including all the original gameplay features except for user registration. The styling is very similar to the original game, with a few minor differences in animations.

## Technologies Used

- JavaScript
- HTML
- CSS

## How to Run the Project

1. Clone the repository.
2. Open the project folder in your code editor.
3. Run the project using Live Server.

## Usage

Type a five-letter word and press Enter to submit your guess.

The tiles change color to provide feedback:

- **Green:** The letter is in the correct word and in the correct position.
- **Yellow:** The letter is in the correct word but in the wrong position.
- **Gray:** The letter is not in the word.

You have six attempts to guess the correct word. If you fail to guess it within six attempts, a popup will reveal the correct word.

After finishing a game, you can start a new game and play again.
